# Zümrüd Parfum. Прототип интернет-магазина

Демонстрационный прототип магазина парфюмерии Zümrüd Parfum (Баку, Насими).
Next.js (App Router), TypeScript, Tailwind CSS. Без бэкенда: товары в одном файле,
корзина в localStorage, оплата имитируется. Заказы никуда не отправляются.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, запуск собранной версии: `npm start`.

## Где что лежит

- `src/data/products.ts`. Все 60 товаров: цены, объёмы, пол, ноты, описания на az и ru.
- `src/i18n/az.ts`, `src/i18n/ru.ts`. Все строки интерфейса. В компонентах зашитых строк нет.
- `src/config.ts`. Константа `SHOW_DEMO_BANNER` (плашка демо на каждой странице) и реквизиты магазина.
- `src/lib/payment.ts`. Имитация оплаты. В продакшне здесь будет вызов epoint.az.
- `public/products/`. Фотографии товаров 800x800 webp и `sources.json` с источником каждой картинки.
- `docs/zumrud-claude-code-prompt.md`. Исходное техзадание.

## Скрипты для фотографий

- `node scripts/fetch-images.mjs`. Скачивает фото по манифесту `scripts/image-sources.json`,
  приводит к 800x800 webp на белом фоне, пишет `public/products/sources.json`.
- `node scripts/make-placeholders.mjs`. Генерирует заглушки (бренд золотом на тёмно-зелёном)
  для позиций, у которых нет файла.
- `node scripts/check-images.mjs`. Проверяет каждый файл: размер, вес, формат, что это не баннер
  и не страница ошибки. Завершается с кодом 1, если есть хоть один fail.

## Деплой

Проект готов к деплою на Vercel без дополнительной настройки: импортировать репозиторий,
фреймворк определится автоматически.
